How Indexing Got 2.7x Faster

Segment term table became xxh3 hash map instead of B-tree
Removed tens of millions of 20-level pointer-chasing B-tree descents
Per-document term grouping became sort over borrowed strings
Deleted per-document B-tree map and its allocations
Document analysis runs on explicit scoped threads in bounded batches
Accumulation stays strictly in row order, proven byte-identical to sequential loop
Seal stopped re-decoding freshly written bytes to count multi-field document frequencies
